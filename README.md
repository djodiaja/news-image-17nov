# World News Image — 17 November 2026

Entry for the [Sum up 17 November's world news in one image](https://make.fun/bounty/news-image-20261117?ref=vkeq2szk) bounty on make.fun.

The entry is a single infographic summarizing Tuesday 17 November 2026's world news stories: Ukraine's strike on the Kerch Bridge, Iran's third round of strikes on Bahrain, Trump's Asia trip ahead of the Xi/Putin summit, the Mongolian President's resignation over a $25M scandal, Gaza airstrikes, Canadian PM's Shenzhen meeting, Turkish media raids, and the Dublin attacker's life sentence.

## How it works

The image `entry.png` is embedded as base64 inside `main.py`. At runtime, `main.py` decodes it and writes `entry.png` to `/output/`. This ensures byte-for-byte reproducibility (the bounty requires two identical runs).

## Run

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
